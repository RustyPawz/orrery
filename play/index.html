Display & performance

The display options only change what's drawn, never the music; turning them off or lowering the frame rate saves CPU and battery. Low-power preset also eases the audio engine below. Saved on this computer.

Audio engine

If the audio crackles, choose Stable (a bigger buffer, a little more delay), Eco effects (shorter reverbs, lighter saturation) or fewer notes per instrument.

Plugins

    A plugin is a .js file that adds new module types. See PLUGINS.md to make your own. Plugins run with full access to ORY-1, so only add ones you trust.
